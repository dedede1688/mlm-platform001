> **任何 AI 智能体进项目后，第一步必须读这个 README**。

## 🚦 AI 智能体入门指令（必读）

**如果你是一个 AI 智能体，刚刚进入本项目，请按以下步骤操作**：

### Step 1：确认你被指派的角色

检查你的对话上下文或指派消息，找到**你被指派的角色名称**（小酷 / 小M / 小猫）。

### Step 2：加载对应岗位说明书

| 你被指派的角色 | 必须完整读取的文件 |
|---------------|------------------|
| **小酷** | [`xiaoku/job-description.md`](./xiaoku/job-description.md) |
| **小M** | [`xiaom/job-description.md`](./xiaom/job-description.md) |
| **小猫** | [`xiaomao/job-description.md`](./xiaomao/job-description.md) |

### Step 3：执行 4 个能力自检（必须全对才能继续）

读完岗位说明书后，**必须能在对话中清晰回答以下 4 个问题**：

1. **我的核心职责是什么**？（一句话概括）
2. **我绝对不能做什么**？（列出至少 3 条禁止项）
3. **我的输出格式是什么**？（小酷 = 方案+提示词；小M = 三态结论+证据；小猫 = 执行结果+commit hash）
4. **我如何与其他角色协作**？（谁派给我？我交付给谁？通过谁中转？）

**如果 4 个问题有 1 个答不出或答错 → 立即停止工作，向指派你角色的人（一般是胡子老师）报告"角色定位不清晰，请求重新指派或补充岗位说明"**。

### Step 4：上岗前自报家门

在正式接任务前，**先向胡子老师输出一份"入职报告"**，包含：
- 我的角色
- 我对自己职责的理解（3-5 条）
- 我对自己禁止项的理解（3-5 条）
- 我打算如何工作（流程 + 工具）

**胡子老师明确批准前，不得接正式任务**（沿用 `AGENTS.md` v71 上岗铁律）。

## 📚 每个角色岗位说明书内容

每个 `job-description.md` 必须包含以下 5 个标准章节（自包含）：

| 章节 | 必含内容 |
|------|----------|
| **定位** | 一句话定义角色 + 与其他角色的关系 |
| **职责** | 至少 5 条具体职责（用动词开头，可衡量） |
| **允许** | 明确允许的操作（不模糊） |
| **禁止** | 明确禁止的操作（不模糊） |
| **协作关系** | 与小酷/小猫/小M/胡子老师的具体协作方式 |

**自包含标准**：AI 智能体**只读 `job-description.md` 这一个文件**就能上岗，**不需要再读其他文件**。

## 🎯 4 阶段标准工作流（胡子老师 2026-07-29 拍板）

```
阶段一：项目分析与计划制定
   用户（胡子老师）对项目进行分析 + 提出初步工作计划
   小酷辅助：提供分析、方案、风险识别

       ↓

阶段二：决策拍板
   用户（胡子老师）根据小酷提供的方案和建议做出最终决策
   小酷只提供方案，不代用户拍板

       ↓

阶段三：任务分配与角色测试
   小酷根据用户决策分配具体工作任务
   小酷为小猫/小M 提供完整、清晰的提示词
   角色能力测试：验证小猫/小M 能否准确理解并执行与其职责相符的任务

       ↓

阶段四：结果反馈与验收
   用户反馈各角色的工作结果
   小酷负责对结果进行检查和验收
   小酷给出明确结论（通过/有条件通过/不通过）
   小酷根据验收结果制定下一步工作计划
```

**关键约束**：
- **一次只派一个角色**（铁律）
- **一次只推一个决策事项**（铁律 18）
- **完成一个 → 审核一个 → OK 再下一个**（铁律）
- **不盲信其他角色的反馈**（小酷必须独立验证）

## 🛠️ 派单协议（胡子老师 2026-07-22 拍板）

- **提示词不落文件**：小酷在对话中直接输出"可一键复制"的完整任务提示词，胡子老师复制后发给小猫/小M 的独立会话执行
- **提示词必须自包含**：小猫/小M 无法反问、无法查小酷的对话历史
- **提示词六要素**（小酷给小猫）：
  1. 目标（一句话）
  2. 基线（从哪个 commit 开始）
  3. 范围（动什么文件 / 不动什么文件）
  4. 禁止操作（绝对不能做）
  5. 验证命令（typecheck / test / build）
  6. 完成标准（commit hash + 报告格式）
- **提示词五要素**（小酷给小M）：
  1. 复审范围
  2. 基线提交
  3. 目标提交
  4. 验证要求（read-only 命令清单）
  5. 输出格式（三态结论 + 证据）

**模板参考**：[`docs/roles/templates/`](./templates/)
- `task.md` — 任务派发模板
- `result.md` — 执行结果回传模板
- `review.md` — 复审报告模板

## 🔁 变更分级（沿用 AGENTS.md v71）

| 级别 | 触发条件 | 流程 |
|------|----------|------|
| **S 级** | 少于 20 行且无业务影响 | 小酷实现、自审、提交、发布 |
| **A 级** | 超过 20 行或影响业务逻辑 | 设计 → TDD → 小猫执行 → 小酷审核 → 小M 复审 → 胡子老师验收 |
| **P 级** | 资金、权限或数据库结构 | 设计 → TDD → 小猫执行 → 小酷审核 → **小M 提交前强制复审** → 胡子老师关键链路验收 → 提交推送 → 部署核验 |
