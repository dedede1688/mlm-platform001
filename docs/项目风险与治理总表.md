## 1. 使用规则

1. 本表是项目风险与治理的**唯一现行总表**。
2. **证据等级**（五种，不得使用其他）：
   - **已确认** — 当前源码、Git 状态或独立命令直接证明
   - **高风险待验证** — 结构存在风险，但尚不能证明生产环境已发生资金损失、重复发放或安全事故
   - **产品决策** — 是否实现由胡子老师决定，不属于代码 Bug
   - **已处理待提交** — 工作区已修改，但尚未 commit、push、部署
   - **历史信息** — 只用于理解背景，不作为当前实现依据
3. 不得把多份报告的相同结论当作独立验证。多份报告可能来自同一次审计传播。
4. 任何新增风险或治理进展，由小酷更新本表。胡子老师可随时要求重新验证任何条目。
