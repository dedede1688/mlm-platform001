## 1. 使用规则

1. 本表是项目风险与治理的唯一现行总表。
2. 证据等级只使用五类：已确认、高风险待验证、产品决策、已处理待发布、历史信息。
3. 多份报告的相同结论不能当作多次独立验证；必须回到源码、测试、Git、生产验收事实。
4. P 级涉及资金、权限、数据库结构，必须设计、验证、小M只读复审、胡子老师拍板。
5. 本表更新只代表治理状态同步；不等于自动授权执行代码、数据库、push 或部署。

