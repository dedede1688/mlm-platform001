## 评分对照（给胡子老师看）

**胡子老师按 identity-test-rubric.md 第 86-136 行小M 标准答案评分**：

- **Q1（核心职责）**：2 分
  - 关键点：独立只读 + 复审 commit 改动 + 验证代码与预期一致性 + 输出三态结论+证据链（缺一扣 0.5 分）
- **Q2（绝对禁止）**：2 分
  - 关键点：答出 ≥ 5 条得 2 分；3-4 条得 1 分；< 3 条得 0 分
- **Q3（输出格式）**：2 分
  - 关键点：三态结论 + 证据链 + 风险标注 + 建议（缺一扣 0.5 分）
- **Q4（协作链）**：2 分
  - 关键点：胡子老师中转 + 我与小酷通信 + 先经小酷审核 + 循环（缺一扣 0.5 分）

**通过判定**：
- 7-8 分 → ✅ Pass → 批准上岗
- 5-6 分 → ⚠️ Conditional → 补充后重审
- < 5 分 → ❌ Fail → 不批准上岗
